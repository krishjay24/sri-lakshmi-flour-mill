# Release checklist and implementation audit

## Confirmed defects in the previous active site
- The contact form called `window.open` and immediately claimed the message was sent and cleared input. A browser handoff is not delivery.
- Product search read the URL only when state initialized, so subsequent header searches and history navigation could show stale results.
- Five active routes had no 404 fallback. Gallery and Process were unregistered.
- WhatsApp number was copied across active components; former contact page also published a precise address and hours without confirmation.
- The old Process page claimed laboratory testing, specialized machinery, traceability and controlled packing without supporting evidence.

## Design and architecture improvements
- A new cohesive responsive layout covers all five active pages plus privacy and 404. Shared navigation, footer, cards, scroll tools and brand tokens are in `src/site/`.
- Existing product names/categories and all eight service names remain the content baseline in `src/data/`. Neutral copy avoids repeating unsupported manufacturing, health and sourcing claims.
- Single business config and encoded WhatsApp helper. The owner-provided WhatsApp number `+91 91002 37150` now powers the floating icon, product/service links, footer and contact page. Valid contact form submissions open a prefilled WhatsApp chat in a new tab and retain the input; an in-page direct link remains available if the browser blocks the opening. No success/delivery claim is made.
- Product filters/search use URL parameters and handle reset, empty states and browser history. Site has keyboard-visible focus, labeled fields, reduced-motion styling and responsive grids.
- Gallery stays offline (no verified facility images); `src/data/gallery.js` is ready for approved assets. Process stays offline because the existing detailed claims are unverified; the homepage presents a safe *enquiry* journey instead of a fictional manufacturing process.
- No analytics or lead events are sent. Privacy policy documents current client-side handoff.
- The original logo image remains unchanged. A transparent, emblem-only derivative (`src/assets/logo/logo-mark.png`) is generated by `scripts/make-logo-mark.ps1`, used in the header and favicon; the business name remains as accessible live text alongside it.
- Existing wheat/flour and chilli cutouts are used only for matching subjects. Missing rice, turmeric and facility photos use neutral placeholders or no section, never an unrelated image.
